Speaker notes and sources

An inference request is a software message from the harness to the model service, asking it to generate a response. The harness sends it automatically when the loop reaches Invoke.

Harness assembles and sends

  • ModelSelected model / route
  • InstructionsSystem/developer guidance + loaded procedures
  • ContextUser prompt + selected history, memory, files and results
  • ToolsAvailable tools, descriptions and argument formats
  • SettingsOutput limit + supported generation controls
Conceptual groups; actual API fields and ordering vary.

No additional user prompt is needed. A state reference can carry prior context instead of resending its full text. One hosted-agent API call may contain multiple internal model requests.
