Portable context-policy workshop
Run: node example.mjs
Requires a modern Node.js with native ES modules and TextEncoder.
No packages, API keys, model calls or harness installation.

context-policy.mjs:
- scopeDependencies: shortest-path BFS. exact is nodes at exactly depth; within includes all visited nodes through depth.
- buildPacket: complete supplied source text plus task/checks in an explicit user-content order.
- requireAnchors: fail when a required anchor is missing. This does not establish that the corresponding facts or constraints survived semantically.

The bundled fixture is synthetic, frozen service-task evidence. It is not production telemetry.
To adapt: replace dependency edges/source mapping; define required facts and acceptance checks; compare policies under matched tasks/model/context; validate behavior independently.
Native integration: bind packet preparation at supported prompt/dispatch boundaries; preserve native role/tool contracts. Checkpoint validation observes completed compaction and restores missing material before the next request. Source-matched OpenCodeV2 snippets in the presentation are illustrative adapters, not runtime-verified plugins for your installed version.
