How to read one attention map

1 · Find a cell. Columns are key positions (tokens being looked at); rows are query positions (tokens doing the looking). Each small panel is one reported layer, head0.

2 · Read the color scale. Warm/red colors indicate higher average attention logits (scores), and cool/blue lower scores. Read each panel’s own color scale; scales differ across panels. Logits are not percentages; each query needs normalization across its accessible keys to get weights. The future-key upper triangle is causally inaccessible.

3 · Compare patterns. Near-diagonal emphasis in layers0/1 indicates local comparisons. A strong first column in later shown layers indicates attention to the initial token: an attention sink, which can attract attention without meaningful task content.

4 · Keep the implication scoped. Large scores do not establish instruction authority, factual importance or task accuracy. This historical Llama-2 example explains a mechanism; it is not a current frontier-model benchmark.

What a harness can do: curate context and verify behavior. The paper’s intervention preserves initial key/value (KV) states while evicting other cached states; implementing that requires serving-layer access. It is not a prompt-cache billing trick or a rule to put every instruction first.
