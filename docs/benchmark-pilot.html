What these runs establish

  • A single delegation contains a worker loop: the first sequential run used 48 model calls across the orchestrator and four worker sessions.
  • Single sessions passed both task checks with fewer requests and less elapsed time than the corresponding sequential orchestration runs in this small pilot. The managed protocol's research, planning, trace and validation overhead is part of the measured treatment.
  • The parallel-requested pagination run completed sequentially. The explicit parallel idempotency run dispatched two researchers, but the harness rejected one with “capacity exhausted”; it did not reach implementation or managed acceptance. Its artifact failed the external check. Both attempts retain their full observed costs.
  • The installed controller defaults to total capacity one and per-role capacity one. Parallel authorization does not raise that ceiling. No successful concurrent-worker or routed-model result is claimed.

Cost is a counterfactual, not a bill

The account is subscription based. Values above apply published Standard API token rates to observed usage; they are neither actual API charges nor subscription quota conversion. No dollar ceiling was applied. All trials used a 10-minute time bound and a 100-request guard.

For each request: [(input − cache-read − cache-write) × 2 + cache-read × 0.10 + cache-write × 2.50 + output × 10] / 1,000,000 USD. Output includes reasoning once. Above 272,000 input tokens, the corresponding full-request rates are 4 / 0.20 / 5 / 15; none of these measured requests crossed that threshold. Cache-write tokens were measured as zero. A cached input still occupies logical context.

Rates verified 5 November 2026: OpenAI model specification and API pricing. API cache behavior, service tier and routing can differ from subscription execution. Tool and infrastructure charges and quota consumption are unavailable.

Evidence and controls

  • Fresh task workspaces and sessions; identical task and evaluator bytes within each task. Single-session delegation tools/guidance removed for that experimental condition. Ordinary tool catalogs matched; managed delegation tools and protocol instructions are intentional differences.
  • Physical provider request IDs correlated with projected terminal usage, then reconciled against persisted native assistant usage in every root and child session. Tool executions and delegation spans counted separately. Raw content and credentials are excluded from public exports.
  • Provider/native usage and request endpoints reconciled for all published runs. Independent external checks ran on frozen task artifacts after process termination was confirmed. The checks are small functional tests, not a representative quality score or an adversarially hidden evaluation.
  • Request/tool/worker durations use one native monotonic clock. Workflow time uses a separate controller clock. Unknown event UTC timestamps remain null; ingestion time is separate. Timing includes native startup, task execution and the external check.
  • Natural provider caching, no forced flush; fixed recorded order B/A/C then A/C/B. No repeat distribution, confidence interval or isolated-load guarantee. Some read-only auditing and controller development occurred on the host. The explicit schedule in the second C prompt differs from the first C prompt.
  • One earlier launch failed workspace selection before task work and was excluded as an infrastructure error; the workspace environment regression is fixed. Preliminary smokes are separate. No failed measured task was discarded.

Portable method; configuration-specific findings

The canonical manifest, per-request accounting, evaluation and comparison format can be reused with another harness. These numerical results have not been replicated elsewhere. The general native executor remains gated pending broader retry, transport and cancellation coverage. No global installed release was changed.

Next prerequisite for a valid parallel study: a tested, owner-controlled capacity option that allows two readers/reviewers while retaining one writer, followed by fresh matched trials. Model-routing and larger representative tasks remain future experiments.
